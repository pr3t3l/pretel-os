# Travels — Personal trip planning & preferences

Bucket: personal  
Status: Active  
Created: 2026-05-18  
Objective: Build a persistent, evolving knowledge base of Alfredo's travel preferences (food, lodging, pace, activities, group composition) so each new trip is planned with higher fidelity to what he actually enjoys. Enable the Router to inject relevant prior lessons whenever a travel planning session starts, scoped by group context (solo/family) and geography.

## Description

Cognitive home for Alfredo's travel preferences, decisions, trip history, and per-trip task lists. Every new planning session (solo or family, any destination) recalls prior preferences and decisions automatically via lesson semantic recall and tag filters. Contains soft preferences (lessons), hard rules (best_practices), firm decisions (decisions), per-trip to-dos (tasks), and trip catalogue (project_state).
