Introducción 
En el ecosistema digital actual, las redes sociales se han convertido en un 
escenario clave para la generación y consumo de contenido. Las marcas, 
influencers y creadores compiten por captar la atención de una audiencia cada 
vez más exigente. En este contexto, la inteligencia artificial (IA) y las 
herramientas de automatización ofrecen nuevas oportunidades para 
aprovechar la información generada por la competencia. Este capítulo explora 
cómo aplicar técnicas de web scraping, transcripción automática y análisis de 
datos para transformar contenido existente en nuevos videos con alto potencial 
de viralización. 
Introducción al Scraping de Contenido de la 
Competencia 
El scraping de contenido consiste en la recopilación automatizada de datos 
públicos disponibles en la web. En el ámbito de las redes sociales, esta técnica 
se utiliza para recolectar información sobre publicaciones, interacciones, 
perfiles y estrategias utilizadas por competidores directos. 
La extracción sistemática de estos datos permite: 
●​ Comprender qué tipos de contenido generan mayor engagement.​
 
●​ Identificar tendencias de formato, estilo y temas recurrentes.​
 
●​ Obtener inspiración para nuevos contenidos adaptados a otras 
audiencias o con un enfoque optimizado.​
 
En el contexto de este capítulo, el objetivo no es solo observar a la 
competencia, sino transformar la información extraída en nuevos productos 
audiovisuales generados mediante inteligencia artificial. Este proceso busca 

                                                          
 
 
maximizar el potencial de viralización mediante la reutilización creativa de 
contenido probado. 
Observaciones Claves 
●​ El scraping se centra exclusivamente en la recopilación de datos 
públicos.​
 
●​ La IA permite reinterpretar esta información en nuevos formatos 
audiovisuales.​
 
●​ El objetivo principal es amplificar la viralidad a partir de contenidos que 
ya han demostrado su efectividad.​
 
Aplicación Apify para el Scraping 
Apify es una plataforma de automatización web que permite crear, ejecutar y 
gestionar scrapers (extractores de datos) de manera estructurada. La 
plataforma cuenta con una comunidad activa y un repositorio —Apify Store— 
con miles de actores preconfigurados para tareas específicas, lo cual simplifica 
considerablemente el proceso de extracción de información desde distintas 
plataformas, incluyendo redes sociales como TikTok, Instagram o YouTube. 
Elementos Clave de Apify 
●​ Apify Store: Contiene una variedad de actores listos para usar, tanto 
desarrollados por Apify como por su comunidad. Estos actores son 
scripts predefinidos que ejecutan tareas de scraping sobre plataformas 
específicas.​
 
●​ Actores: Son programas automatizados que extraen datos concretos. 
Por ejemplo, el actor “TikTok Scraper” puede recolectar datos de videos, 
descripciones, hashtags, número de likes y más desde un perfil 
específico.​
 
●​ API Key: Es una clave única que permite acceder a los actores desde 
plataformas externas. Para integraciones automatizadas, como las que 

                                                          
 
 
se realizan desde Make.com, esta clave es esencial.​
 
Observaciones Claves 
●​ Apify permite escalar procesos de scraping mediante actores 
reutilizables y configurables.​
 
●​ La API Key habilita la conexión con flujos de trabajo automatizados.​
 
●​ La variedad de actores permite realizar scraping de múltiples 
plataformas con facilidad.​
 
Proceso en Make.com 
Make.com (anteriormente Integromat) es una plataforma de automatización que 
permite conectar múltiples aplicaciones mediante flujos visuales. En este 
proceso, Make.com se utiliza para orquestar la interacción entre Apify 
(extracción), ChatGPT (transcripción) y Google Sheets (almacenamiento). 
Configuración del Flujo de Trabajo 
1.​ Módulos de Apify:​
 
○​ Run Actor: Ejecuta el scraper de TikTok para obtener información 
de perfiles o publicaciones específicas.​
 
○​ Get Dataset Items: Recupera los datos extraídos (como URLs de 
videos, descripciones, etc.).​
 
2.​ Módulo HTTP:​
 
○​ Descarga los videos obtenidos por el actor, utilizando sus URLs.​
 
3.​ Módulos ChatGPT (Whisper):​
 

                                                          
 
 
○​ Transcriben el contenido de los videos mediante la tecnología de 
reconocimiento de voz Whisper.​
 
○​ Se puede definir el idioma para obtener mejores resultados de 
precisión.​
 
4.​ Módulo Router:​
 
○​ Filtra los contenidos en función del idioma detectado, enviándolos 
a rutas de transcripción adecuadas.​
 
5.​ Módulo Google Sheets:​
 
○​ Almacena los datos estructurados, incluyendo texto transcrito, 
nombre del creador, hashtags, número de visualizaciones, etc.​
 
○​ Esto permite un análisis posterior o su uso como base para la 
creación de nuevo contenido.​
 
Observaciones Claves 
●​ La integración de Make.com permite crear procesos automatizados y 
reproducibles.​
 
●​ Cada módulo cumple una función específica y debe ser configurado 
cuidadosamente.​
 
●​ La transcripción automatizada es un paso esencial para transformar 
contenido audiovisual en texto reutilizable.​
 
Limpieza y Preparación de Datos 
Tras la transcripción y almacenamiento, se realiza una fase crítica de curación 
de datos. Esta etapa asegura que los textos obtenidos sean útiles y de calidad 
para los siguientes pasos del flujo creativo. 

                                                          
 
 
Proceso de Limpieza 
●​ Eliminación de transcripciones incompletas: Se descartan aquellas que 
sólo contienen música, efectos de sonido o palabras aisladas sin valor 
semántico.​
 
●​ Normalización de texto: Se corrigen errores de transcripción, se eliminan 
caracteres no deseados y se estructura el texto para facilitar su análisis.​
 
●​ Filtrado de contenido no relevante: Se excluyen temas que no se alineen 
con el objetivo del proyecto o que no tengan potencial viral.​
 
Observaciones Claves 
●​ La limpieza garantiza que el contenido generado por IA sea coherente, 
relevante y eficaz.​
 
●​ Filtrar transcripciones pobres mejora significativamente la calidad del 
producto final.​
 
●​ Solo los datos curados pasan a la etapa de generación de nuevos 
videos.​
 
Conclusión 
Este flujo de trabajo, que integra scraping automatizado, transcripción asistida 
por inteligencia artificial y limpieza de datos, constituye una estrategia efectiva 
para la generación de contenido digital competitivo. Al analizar y reutilizar 
contenido exitoso de la competencia, las marcas y creadores pueden optimizar 
sus propios esfuerzos creativos y aumentar sus probabilidades de viralización. 
La combinación de herramientas como Apify, Make.com, ChatGPT y Google 
Sheets ofrece una infraestructura flexible y potente, que permite escalar la 
producción de contenido inteligente, basado en datos reales y validados por el 
comportamiento de los usuarios en redes sociales.
